# Промт: локальна копія drone.riotters.com

Це не інструкція «напиши код із нуля» — це посилання на вже готовий, перевірений
код сайту. Результат гарантовано 1:1, бо це той самий код і файли оригіналу, не
відтворення.

## Що зробити

1. Завантажити архів: **https://github.com/09designernixtio-ui/Test/blob/main/promt-lokalnyi.zip**
   (репозиторій приватний — відкриється тільки в того, кого додано як колаборатора;
   на сторінці файлу натиснути "Download raw file")
2. Розпакувати.
3. Встановити Node.js, якщо немає: https://nodejs.org
4. У розпакованій теці виконати:
   ```bash
   node mirror-server.mjs
   ```
5. Відкрити в браузері: **http://localhost:5190/**

Результат: сайт, ідентичний drone.riotters.com — той самий HTML/JS/CSS, та сама
3D-модель дрона, ті самі відео й анімації, повністю офлайн (перевірено: 0 запитів
у мережу після запуску, 0 помилок у консолі).

## Обмеження

- Це код і матеріали компанії **Riotters** (3D-модель, відео, текст, бренд). Доступ
  до цього репозиторію приватний — не поширювати далі без дозволу власника матеріалів.
- Код усередині — мінімізований Next.js/React-бандл, редагувати його напряму
  практично неможливо. Це копія для перегляду/вивчення, не основа для власного сайту.
